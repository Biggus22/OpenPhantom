This is the VOR ILS panel.  It is heavily WIP and will likely receive several revisions.

It requires:

100nf 1206 capacitors x 12

JST PH 3pin SMD headers x 2**

JST PH 2pin SMD header x 1*

SK6812 Mini-E RGB LEDs x 7

10k 1206 resistors x 3

220R 1206 resistors x 1

EC11EBB24C03 concentric rotary encoder x 1 (this may be substituted with a single EC11 encoder with push button switch for emulation)

ST7789 172x320 IPS LCD display x 1

Wemos S2 Mini ESP23S2 x 1

7x7mm tactile switch x 1*

RK097 vertical potentiometers x 2**

* denotes user choice of board-mounted 7x7 tactile switch or JST PH 2P header with user's own pushbutton switch.

* * denotes user choice of board-mounted RK097 potentiometers of JST PH 3P header with user's own potentiometers.
