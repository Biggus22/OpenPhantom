X27.168 or clone x 1
5mm TH LED x 4
1206 resistor, 47R x 2
1206 resistor, 220R x 1
1206 resistor, 10K x 2

Optional parts:
MBR0520 SOD-123 x 8 (these can often be omitted but are included for completeness)
ITR-9606 optical interrupt x 1 (optional positional sensor)
A3144EUA hall switch x 1 (optional positional sensor)


You will likely need to remove a nub from one of the internal gears in the X27.  There are several videos on this process.
The interrupt and hall switch are not able to be used at the same time.  You will also want to have a small magnet if you use the hall switch option.
